# RelayOps
A production incident workflow platform with grounded AI diagnosis. Ingests financial integration incidents, runs them through eight quality gates, and deploys with hardened security, observability, and recovery drills.

## Build log

Each quality gate gets a recap doc capturing what was built, why, and what
broke along the way — see [`docs/gates/`](docs/gates/). Architecture
decisions are recorded separately in [`docs/adr/`](docs/adr/).
